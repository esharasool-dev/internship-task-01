# Resume Website

## About the Project
This is my first internship project. It is a resume website created using HTML5 and CSS3 to present my introduction, education, skills, and projects in a clean and organized layout.

## Features
- Simple and clean design
- Semantic HTML5 structure
- Responsive layout for different screen sizes
- About, Education, Skills, Projects, and Contact sections
- Smooth scrolling navigation

## Technologies Used
- HTML5
- CSS3

## Project Structure

personal-resume/
├── index.html
├── style.css
└── README.md

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Purpose
The purpose of this project is to practice semantic HTML, CSS styling, responsive design, and basic website development.

This project was created as part of my internship learning journey.
